# Data Model & Interface Contracts\n\n## Data Model\n\n### `RoutineState`\nRepresenta el estado reactivo principal del generador de rutinas en Vue.\n- `patientName`: String\n- `date`: String (YYYY-MM-DD)\n- `notes`: String\n- `amRoutine`: Array of `RoutineStep`\n- `pmRoutine`: Array of `RoutineStep`\n\n### `RoutineStep`\nRepresenta un paso individual dentro de una rutina.\n- `id`: String (UUID o timestamp para key rendering)\n- `type`: String (ej. "Limpieza", "Contorno de ojos", "Sérum")\n- `product`: String (Nombre del producto sugerido)\n- `instructions`: String (Indicaciones de aplicación)\n\n## Validation Rules\n- Un paso de rutina no debe enviarse vacío al servidor (filtrar antes de guardar).\n- El nombre del paciente puede ser auto-poblado desde las props del componente padre (`PatientDetail.vue`).\n\n## State Transitions\n- `isEditing`: Boolean. Alterne entre true (inputs y textareas editables) y false (renderizado de texto plano para generar el PDF de forma prolija).\n
